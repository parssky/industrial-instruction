# Configuration reference

## The starter file

This is the file `ii init` writes. It lists every user-facing setting with
its default:

```yaml title="industrial_instruction.yaml"
--8<-- "src/industrial_instruction/configs/default.yaml"
```

## All settings

Every section is a model in
[`config.py`](https://github.com/parssky/industrial-instruction/blob/main/src/industrial_instruction/config.py).
These tables are generated from that file on every docs build, so they
always match the code. Unknown keys are rejected.
